# Siemens Symbia, LEHR (Low-Energy High-Resolution) collimator + NaI crystal.
# Sensitivity at 10 cm: 7.5e-5 counts/decay as this preset builds the holes, against the 9.1e-5
# reference (ratio 0.82); 1.07e-4 (ratio 1.18) if the holes are built hexagonal. See
# docs/validation.md section 3, which records why the previously quoted ratio of 0.95 was two
# compensating errors.
# Geometry 1.11/0.16/24.05 mm. NOTE: the real Symbia LEHR collimator is HEXAGONAL holes on a
# hexagonal lattice, and the dimensions above are its flat-to-flat values, but this preset sets
# neither HoleShape nor Lattice and therefore builds ROUND holes on a SQUARE lattice. That is 1.40x
# less sensitive, since sensitivity scales as (open fraction) x (hole area). Add
#   s:Ge/Collim/HoleShape = "Hex"
#   s:Ge/Collim/Lattice   = "Hex"
# in the including deck to model the real hole shape, and remember that a hexagonal lattice needs
# about 1.155x more ROWS than columns to cover the same crystal. Sources: Dong 2018 (MCNP5, Symbia T);
# Rodrigues 2007 (Geant4, e.cam); Asmi 2019. Reliability B (Siemens collimator geometry is
# vendor-proprietary; published values are third-party MC reconstructions).
# See research/knowledge/spect-collimator-geometry/.
#
# IncludeFile fragment. Defines materials + Ge/Collim (hole/septum/length) + Ge/Crystal
# (material + thickness). The including deck must add World, physics, source, scorer, the
# detector extents (NHolesX/Y, Crystal HLX/HLY, XBins/YBins) and the Z placements below.
# See systems/README.md for the full contract. Include exactly one preset per deck.
#
# Recommended placement (front collimator face at z = 0):
#   d:Ge/Collim/TransZ  = 12.025 mm     # CollimatorLength / 2
#   d:Ge/Crystal/TransZ = 29.05 mm      # 0.25 mm gap behind the collimator back face
# Photopeak window (apply in post-processing): Tc-99m 140.5 keV, 20% -> 126.5-154.6 keV.
# Fast-path (TsForcedDetectionProjection) collimator numbers:
#   HoleDiameter 1.11 mm, SeptalThickness 0.16 mm, CollimatorLength 24.05 mm.

# --- Collimator septa: lead ---
sv:Ma/Lead/Components = 1 "Lead"
uv:Ma/Lead/Fractions  = 1 1.0
d:Ma/Lead/Density     = 11.35 g/cm3

# --- Crystal: sodium iodide ---
sv:Ma/NaI/Components = 2 "Sodium" "Iodine"
uv:Ma/NaI/Fractions  = 2 0.1534 0.8466
d:Ma/NaI/Density     = 3.67 g/cm3

# --- Collimator geometry (LEHR) ---
s:Ge/Collim/Type             = "TsParallelHoleCollimator"
s:Ge/Collim/Parent           = "World"
s:Ge/Collim/Material         = "Lead"
d:Ge/Collim/HoleDiameter     = 1.11 mm
d:Ge/Collim/SeptalThickness  = 0.16 mm
d:Ge/Collim/CollimatorLength = 24.05 mm
s:Ge/Collim/Hole/Material    = "Vacuum"

# --- Crystal geometry (NaI, 9.5 mm thick) ---
s:Ge/Crystal/Type     = "TsBox"
s:Ge/Crystal/Parent   = "World"
s:Ge/Crystal/Material = "NaI"
d:Ge/Crystal/HLZ      = 4.75 mm         # 9.5 mm thick
