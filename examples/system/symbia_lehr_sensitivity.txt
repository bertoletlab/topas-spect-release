# Full-MC system example: absolute system sensitivity, Siemens Symbia LEHR + NaI at 10 cm.
#
# Selects the scanner geometry with a single IncludeFile, then adds the world, physics, source,
# scorer, detector extents and placements. Result: 7.5e-5 counts/decay against the 9.1e-5 reference,
# ratio 0.82 (docs/validation.md section 3).
#
# THIS DECK PREVIOUSLY REPORTED 8.6e-5 AND A RATIO OF 0.95. That agreement was two errors
# cancelling, and both are now corrected or documented:
#   1. NHolesX/Y were 120, giving a 152.4 mm collimator over a 180 mm crystal. An obliquely incident
#      photon aimed at the crystal edge then crossed only 21 percent of the collimator length before
#      leaving through its side, reaching the detector through far less lead than a full-length path.
#      Measured contribution: +15 percent. It is peripheral septal penetration rather than photons
#      bypassing the collimator, which an opaque-septa control confirms, being insensitive to the
#      same coverage change. Hole counts are now 158 x 158, a 10.3 mm margin on both axes.
#   2. The preset builds ROUND holes on a SQUARE lattice; the real Symbia LEHR is hexagonal on a
#      hexagonal lattice. Sensitivity scales as (open fraction) x (hole area), so hex-on-hex is
#      1.40x this geometry. Measured on this deck: round 7.4870e-5, hex 1.0722e-4, ratio 1.432
#      against 1.404 derived. The hole shape is NOT changed here, since that is a modelling choice
#      rather than a defect, but the 0.82 ratio is a round-hole number and must be read as one.
#
# In post-processing, count the events whose deposited energy falls in the Tc-99m photopeak
# window (126.5-154.6 keV) and divide by NumberOfHistoriesInRun to get counts/decay.
#
# Run from this example's folder so the relative include resolves:
#   topas symbia_lehr_sensitivity.txt

IncludeFile = ../../systems/symbia_lehr.txt      # Ma/Lead, Ma/NaI, Ge/Collim, Ge/Crystal (spec)

i:Ts/NumberOfThreads = 0
i:Ts/ShowHistoryCountAtInterval = 20000000   # one progress line per N histories, not one per history
b:Ge/QuitIfOverlapDetected = "True"

sv:Ph/Default/Modules     = 1 "g4em-penelope"
b:Ph/Default/Fluorescence = "True"
d:Ph/Default/CutForGamma    = 0.05 mm
d:Ph/Default/CutForElectron = 0.05 mm

d:Ge/World/HLX = 250. mm
d:Ge/World/HLY = 250. mm
d:Ge/World/HLZ = 200. mm
s:Ge/World/Material = "Vacuum"

# Detector extents + placement (the spec-fixed hole/septum/length/material come from the preset).
# NHoles give a 10.3 mm collimator margin beyond the crystal on both axes, so no oblique path
# reaches the detector through a shortened lead thickness.
i:Ge/Collim/NHolesX = 158
i:Ge/Collim/NHolesY = 158
d:Ge/Collim/TransZ  = 12.025 mm            # front collimator face at z = 0

d:Ge/Crystal/HLX    = 90. mm
d:Ge/Crystal/HLY    = 90. mm
d:Ge/Crystal/TransZ = 29.05 mm

# Isotropic point source at 10 cm in front of the collimator
s:Ge/Src/Type   = "TsBox"
s:Ge/Src/Parent = "World"
s:Ge/Src/Material = "Vacuum"
d:Ge/Src/HLX = 0.01 mm
d:Ge/Src/HLY = 0.01 mm
d:Ge/Src/HLZ = 0.01 mm
d:Ge/Src/TransZ = -100. mm

s:So/Beam/Type = "Isotropic"
s:So/Beam/Component = "Src"
s:So/Beam/BeamParticle = "gamma"
d:So/Beam/BeamEnergy = 140.5 keV
i:So/Beam/NumberOfHistoriesInRun = 200000000

s:Sc/Spec/Quantity   = "EDepSpectrum"
s:Sc/Spec/Component  = "Crystal"
s:Sc/Spec/OutputType = "ASCII"
s:Sc/Spec/OutputFile = "sensitivity_symbia_lehr_140p5keV_10cm"
s:Sc/Spec/IfOutputFileAlreadyExists = "Overwrite"
b:Ts/PauseBeforeQuit = "False"
